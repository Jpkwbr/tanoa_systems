Chiffrage forfait

Processus pour fixer le prix d’une mission au forfait. Le socle accélère la livraison ; le client paie le livrable, pas nos heures réelles.

Brouillon non référencé depuis la feuille de route. Orienté Phase 0 : le coefficient ci-dessous est une hypothèse de départ à confronter aux missions réelles (temps passé vs forfait accepté / refusé).

En une phrase

Stratégie

On vend un résultat au forfait. On ne facture pas nos jours réels : on applique un coefficient sur l’effort réel pour garder une marge de productivité (sélectivité + socle + environnement maîtrisé).
  • Pas de TJM public × jours réels (terrain des ESN / régie).
  • Jamais afficher au client la charge en j·h, ni un TJM, ni un décompte de jours — ni dans la proposition, ni à l’oral, ni sur la vitrine / fiche offre. Uniquement : livrable, lots, critères d’acceptation, prix forfait HT (et jalons de facturation).
  • ~1 000 € / j·h = référence interne (cadrage, avenants hors scope), pas le tarif de vente affiché.
  • Découverte et cadrage : non facturés à part, mais inclus dans l’effort A — avec un plafond de charge (voir ci-dessous).

Pré-vente

Plafonds découverte & cadrage

Sinon le pré-vente mange la marge (et le CDI). Pas de cadrage profond avant un go grille 02 ; pas de devis ferme sans inputs client.

Règle rapide : pré-vente ≤ ~10–15 % du lot 1 envisagé (ex. lot 1 ~20 j·h → pré-vente max ~2–3 j·h).

Processus

Étapes (Phase 0)

  1. Filtrer — signaux verts + grille d’évaluation. Ne pas cadrer en profondeur un no-fit.
  2. Estimer A — j·h réels avec le socle, y compris découverte + cadrage.
  3. Choisir le coefficient selon le type de mission (grille 02) :
    TypeCoefficientQuand
    Investissement × 3 La mission enrichit surtout le patrimoine (composants, outillage, conventions) — levier partiel sur le runtime existant
    Exploitation × 4 La mission tire pleinement parti du socle (bus, services, alerting…) — écart max vs ESN sans patrimoine
    Si les deux sont réels : prendre le dominant ; si l’exploitation est nette → × 4. Ces valeurs sont des hypothèses de départ à valider sur les missions.
  4. Fixer le forfait —
    Forfait = A × coefficient × 1 000 €
  5. Afficher au client
    On montreOn ne montre jamais
    Lots, critères d’acceptation, prix forfait HT (et jalons de facturation) Charge j·h, TJM, décompte de jours
  6. Proposition signée — jalons de facturation (ex. 40 % signature / 60 % recette du lot).
  7. Livrer / recetter — hors scope → avenant (référence interne ~1 000 € / j·h).

Apprentissage

Évaluer le coefficient

Le vrai levier de chiffrage Phase 0 : mesurer si ×3 / ×4 tiennent selon le type Investissement / Exploitation.

Après chaque mission (signée ou non) :

  • Type — Investissement / Exploitation / mixte (dominant).
  • A réel — j·h effectivement passés (pré-vente + delivery).
  • Forfait — prix proposé / accepté / refusé.
  • Coefficient implicite — forfait ÷ (A × 1 000 €).
  • Lecture — comparer à 3 ou 4 selon le type ; accepté trop facilement → coef peut monter ; refusé sur le prix (périmètre OK) → baisser un cran ou découper le lot ; dérapage de A → revoir l’estimation, pas seulement le coef.

Après 2–3 missions, recalibrer ×3 / ×4 par type. C’est ça l’objet d’apprentissage — pas d’inventer un B ESN.

Budget client

Intégrer C dans l’équation

On calcule d’abord P = A × coefficient × 1 000 € (coef 3 ou 4). Le budget client C (s’il est connu) sert ensuite à trancher — pas à fixer le prix tout seul.

SituationAction
C ≥ P Proposer P (pas remonter jusqu’à C « parce qu’il y a de la place » sans valeur ajoutée au scope).
A × 1 000 € ≤ C < P 1) Réduire le périmètre / lots pour que le nouveau P′ ≤ C ; ou
2) Accepter une marge plus basse en conscience (référence Phase 0, fit exceptionnel) ; ou
3) Refuser poliment si le ticket ne vaut pas le dérangement CDI.
C < A × 1 000 € No-go ou lot minimal redécoupé — en dessous du plancher on travaille à perte.
C inconnu Proposer P. La réaction du client (ok / trop cher) alimente l’apprentissage du coefficient.
  • Demander C en découverte / cadrage si possible (« vous avez une enveloppe ? ») — sans ancrer le devis dessus.
  • Ne pas annoncer P puis le baisser jusqu’à C sans changer le scope (avenant / re-cadrage).
  • Après coup : si C était connu et P accepté/refusé → noter le coefficient implicite pour recalibrer ×3 / ×4.

Plus tard

Autre ancrage externe

Devis concurrent cité par le client : même logique que C (comparer à P, ajuster scope ou refuser). Ce n’est pas une étape obligatoire du chiffrage.

Prix

Forfait = 9 × 4 × 1 000 € = 36 k€ HT.

  • Client : livrable + critères + forfait — sans voir les 9 j·h.
  • Nous : 4 000 € / j·h effectif — marge = exploitation du socle.
  • Pré-vente (3 j·h) absorbée dans le forfait.

Facturation (après signature)

  • 40 % à la signature → 14,4 k€
  • 60 % à la recette du lot → 21,6 k€

À éviter

Anti-patterns

  • Aligner le devis sur A × 1 000 € « parce qu’on va vite » (oublier le coefficient).
  • Afficher un TJM, une charge en j·h ou un nombre de jours au client.
  • Inventer un « prix marché ESN » qu’on ne connaît pas pour justifier le devis.
  • Facturer découverte / cadrage à part (sauf offre cadrage payant décidée explicitement plus tard).
  • Cadrer en profondeur avant un go grille 02, ou dépasser les plafonds pré-vente.
  • Continuer un cadrage sans inputs client (à la place : pause / relance).
  • Baisser le prix pour « passer » un no-fit.
