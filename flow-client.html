Étapes

Inputs client & livrables

Étape Objectif Inputs client Nos livrables Template
0. Premier contact Accuser réception, proposer un appel découverte Canal de contact ; disponibilité pour un appel Réponse sous 48 h ; proposition d’appel 30–45 min 00
1. Appel découverte Comprendre le besoin ; préparer le go / no-go Contexte métier ; systèmes ; contraintes ; critère de succès ; décideur & timing Notes internes 01
2. Évaluation Décision go / no-go / go conditionnel Notes découverte ; contraintes dispo Grille remplie ; motif si no-go 02
3. Cadrage Périmètre et chiffrage fiables Docs / APIs / schémas ; exemples de flux ; interlocuteur technique ; environnements Besoin reformulé ; périmètre in/out ; lots + critères ; hypothèses ; chiffrage 03
4. Proposition Décision client Validation écrite du périmètre ; circuit de signature / facturation Proposition forfait ; conditions de facturation 04
5. Kickoff Démarrer le lot 1 sans ambiguïté Accès repo / VPN / environnements ; contacts ops ; rythme de points CR kickoff ; planning lot 1 ; canaux & rituels 05
6. Delivery Livrer et faire recetter Retours sous délai ; décisions bloquantes ; jeux d’essai si besoin Code / config / doc ; démo ; PV ou mail de recette 06 liv. · 06 rec.
7. Clôture Clore le forfait ; capitaliser Recette finale ; éventuel retour d’expérience Passation ; inventaire ; demande de retour ; suite éventuelle 07 · retour

Règles

Non négociables

  • Pas de devis ferme sans étape 3 (périmètre + critères d’acceptation).
  • Tout hors périmètre après signature → avenant, pas absorption silencieuse.
  • Priorité au besoin ; une solution technique dictée par le client se reformule en besoin avant chiffrage.
  • Fit interne (go / no-go) : la mission exploite et/ou enrichit le système de production (voir principes fondateurs). Sinon, écarter.
