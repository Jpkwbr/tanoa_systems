Pipeline opportunités

Organisation minimale pour suivre les opportunités et capitaliser — y compris les missions avortées : tableur + dossiers.

Complète flow-client.html (process commercial / livraison) et 02 évaluation (go / no-go). Owner pipeline : rôle Commercial & cadre.

Principe

Deux artefacts, une règle

  • Pipeline — une ligne par opportunité (vue d’ensemble).
  • Dossier — un répertoire par opportunité (preuves et docs).

Pas de statut dans le pipeline sans dossier. Pas de no-go / silence classé sans motif écrit dans le dossier.

Pipeline

Tableur (1 onglet suffit)

Outil libre : Google Sheet, Calc, Notion table — l’important est le partage binôme.

Colonne Contenu
IdCourt, stable — ex. 2026-03-acme
Client / contactNom + canal
Besoin (1 ligne)Reformulation métier, pas la stack
Étape flowVoir statuts ci-dessous
Prochaine actionQui · quoi · date
IssueOuvert / Go / No-go / Silence / Gagné
Motif (si clos)Une phrase
Lien dossierURL ou chemin

Statuts étape (alignés flow-client)

StatutSignifie
0 ContactPremier échange / réponse envoyée
1 DécouverteAppel fait ou planifié
2 ÉvalGrille go/no-go en cours ou faite
3 CadrageInputs / périmètre
4 PropositionDevis / proposition envoyée
5+ MissionSigné → suite flow-client
Z ClasséClos sans mission (no-go, silence, refus)

Dossier

Arborescence type

Un dossier partagé (Drive, Nextcloud, etc.) :

opportunites/
  _pipeline.ods          ← ou lien vers le sheet
  2026-03-acme/
    00-mails/            ← EML / PDF / captures utiles
    01-decouverte/       ← notes (template 01)
    02-evaluation/       ← grille 02 + motif
    03-cadrage/          ← si atteint
    04-proposition/      ← si atteint
    README.md            ← 5 lignes : contexte, issue, motif

Même si ça s’arrête à l’étape 0 ou 1 : on crée le dossier et on écrit le motif. C’est ça, capitaliser sur une mission avortée.

Déclencheurs

Quand créer / mettre à jour

ÉvénementAction
Contact entrant ou premier message sortant utile Ligne pipeline + dossier + 00-mails

Fin découverte / doute de fit Grille 02 ; statut → 2 puis Go / No-go
